# ⚡ Volt v0.2 — Upgrade Guide

What changed since v0.1 and how to make the new features work.

---

## 1. 🎨 Themes & Appearance

- **Theme modes:** Dark · Light · System (follows the OS)
- **Accent colours:** 6 presets (Violet, Cyan, Emerald, Amber, Rose, Indigo)
- Implemented with **CSS custom properties** (`--accent`, `--bg`, `--fg`, …) so
  everything recolours instantly — no rebuild, no reload.

> [!TIP]
> All colours are persisted to `settings.json` and restored on launch.

**Files:** `ui/src/lib/theme.ts`, `ui/src/styles.css`, `ui/src/components/AppearanceTab.tsx`

---

## 2. 🌐 Language (i18n)

- **English 🇬🇧** and **ไทย 🇹🇭**
- Zero-dependency typed dictionary + `useT()` hook
- Persists to `settings.json` → `language`

**Files:** `ui/src/lib/i18n.ts`

To add a language: duplicate the `en`/`th` blocks, add the code to
`LANGUAGES`, and reference it in `dictionaries`.

---

## 3. 🗺️ Canvas (Plan view)

- A right-hand panel that renders the agent's live plan
- Each step has `pending` / `in_progress` / `completed` + a progress bar
- Toggled by the **Plan** button in the titlebar

**Rust commands:** `get_plan`, `set_plan`, `update_plan_step`  
**Event:** `plan://updated`  
**Files:** `src-tauri/src/commands/plan.rs`, `ui/src/components/Canvas.tsx`

---

## 4. 🔌 MCP Servers

Volt is now a **Model Context Protocol client** (stdio, JSON-RPC 2.0).

- Add servers in **Settings → MCP Servers** (presets: Filesystem, Git, Fetch, Memory)
- Their tools auto-merge as `server__tool` and always require approval
- Enabled servers auto-connect on startup

**Files:** `src-tauri/src/mcp.rs`, `src-tauri/src/commands/mcp.rs`, `ui/src/components/McpTab.tsx`

Example preset: `npx -y @modelcontextprotocol/server-filesystem .`

---

## 5. 🧩 Skills & Plugins

- Prompt-injected behaviours with an optional slash command (`/docker`)
- Enable/disable per skill; active skills are appended to the system prompt
- **Settings → Skills & Plugins**

**Files:** `src-tauri/src/commands/plugins.rs`, `ui/src/components/PluginsTab.tsx`

---

## 6. 🗜️ Context compaction

- Estimates conversation tokens (~4 chars/token)
- When usage passes **threshold × context window**, older turns fold into a
  system summary; recent turns stay verbatim
- Tune in **Settings → General** (master switch, threshold, keep-recent)
- A notice appears in the composer when compaction fires

**Files:** `src-tauri/src/compaction.rs`, `Event: ai://compacted`

---

## 7. 🔄 Auto-update (GitHub)

- On launch Volt queries the GitHub Releases API for `owner/repo`
- If a newer tag exists, a **banner** appears with one-click download + install
- Manual check: **Settings → About → Check for updates**

**Configure the repo:**
```bash
# at build time
set VOLT_GITHUB_REPO=owner/repo
```
or edit the fallback in `src-tauri/src/updater.rs`.

**Publish a release:**
```bash
git tag v0.2.0
git push origin v0.2.0
```
GitHub Actions (`.github/workflows/release.yml`) builds and uploads the
installers, and the updater picks them up automatically.

**Files:** `src-tauri/src/updater.rs`, `ui/src/components/UpdateBanner.tsx`, `ui/src/components/AboutTab.tsx`

---

## 8. 📦 Installer

- Custom violet header + sidebar artwork (generated by `generate-installer-art.ps1`)
- EN / TH language selector
- Start-menu folder "Volt", `currentUser` install (no UAC)
- LZMA compression

Regenerate artwork:
```bash
cd src-tauri
powershell -ExecutionPolicy Bypass -File generate-installer-art.ps1
```

---

## ⚠️ Notes

- The updater's `pubkey`/signature verification is optional — Volt uses the
  GitHub Releases API directly, so no Tauri signing key is required for the
  update flow to work.
- If a feature that needs a network call (update check, MCP connect) fails, the
  app logs a warning and continues — nothing blocks startup.

# ⚡ Volt v0.2.1 — What's new

A smaller, focused release: reasoning controls, a policy-driven approval gate
and a calmer chat.

## 1. 🧠 Thinking level

- Pick **Auto · Off · Low · Medium · High** from the composer (brain icon).
- Sent to each provider on its native knob:
  - OpenAI-compatible → `reasoning_effort`
  - Gemini → `generationConfig.thinkingConfig.thinkingBudget`
  - Anthropic → `thinking.budget_tokens` (with an auto-lifted `max_tokens`)
- `Auto` omits the field so the model defaults apply.

**Files:** `src-tauri/src/ai/types.rs` (`ThinkingLevel`), `ai/{openai,gemini,anthropic}.rs`,
`agent/mod.rs`, `ui/src/components/ChatPanel.tsx`

## 2. 🗜️ Context meter

- Live `used / window · %` bar under the composer; goes amber near the
  compaction threshold.
- Compaction still emits `ai://compacted`; the notice now persists for the turn.
- New command: `context_tokens(messages, provider_id)`.

## 3. 🛡️ Approval policy is honoured

- `ApprovalPolicy::needs_approval(tool_name, fallback)` maps your Settings
  toggles onto the gate. MCP/unknown tools fall back to the tool default.
- Approval requests now carry a `preview`: a numbered file preview, a real
  **unified diff** for `apply_patch`, or the command line.

**Files:** `src-tauri/src/config.rs`, `agent/mod.rs`, `ui/src/components/ApprovalCard.tsx`

## 4. 🐛 Fixes

- Explorer no longer blank after restart (`current_project` re-scans the tree).
- `prompt.rs` build break (`build_thinking_section` was missing).
- Dead code removed; `ConfigStore` now uses `parking_lot` like the rest of state.

## 5. 🎨 Chat polish

- Auto-growing composer, collapsible tool/reasoning rows, copy button,
  smarter collapsed tool summaries, keyboard hints, sticky auto-scroll.

**Tests:** 17/17 passing (`cd src-tauri && cargo test`).
